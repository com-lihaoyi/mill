= Kotlin Multiplatform
:language: Kotlin
:language-small: kotlin

This page contains examples of using Mill to build
https://kotlinlang.org/docs/multiplatform.html[Kotlin Multiplatform] projects,
sharing code between platforms such as the JVM, Kotlin/JS and Android.

NOTE: Kotlin Multiplatform support is experimental. It currently supports JVM,
Kotlin/JS and Android platforms, and requires Kotlin 2.0 or later.

=== Renamed targets

The source sets of a platform module are named after it, while the compiler
depends on its traits. So a JVM platform named `desktop`, like `jvm("desktop")`
in the Kotlin Gradle plugin, compiles `src/desktopMain` and `src/commonMain`:

[source,scala]
----
object desktop extends PlatformModule
----

To use source sets named differently from the module, override `kmpPlatform`:

[source,scala]
----
object app extends PlatformModule {
  def kmpPlatform = "desktop" // compiles `src/desktopMain`, not `src/appMain`
}
----
